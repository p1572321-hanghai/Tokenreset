Subagent（子代理）调用算不算额度？用量分摊规则

当主账号发起任务并调用 Subagent 时，产生的用量如何在主账号和子代理之间分摊，是很多用户关心的问题。

Subagent 的调用机制

Subagent 是主账号下创建的子代理，可独立执行子任务。调用时主账号会发起请求，子代理在沙箱环境中运行，最终将结果返回主账号。整个调用链可能包含多轮 LLM 交互。

用量如何计算

根据当前主流实现，Subagent 产生的所有 LLM 调用用量统一计入主账号的额度。子代理本身没有独立额度，它消耗的是主账号的配额。

实际影响

  • 一次主账号请求可能触发多个 Subagent 调用，消耗多倍消息额度
  • Subagent 的 thinking 和工具调用 token 全部计入主账号
  • 长任务链可能快速耗尽主账号的每日额度

常见问题

Subagent 失败了还扣额度吗？

扣。只要 LLM 调用发生，无论任务成功或失败，已消耗的 token 和消息次数都会计入额度。

可以限制 Subagent 的用量吗？

部分平台支持设置单任务的 token 上限和最大调用轮次，建议配置以避免意外超额。

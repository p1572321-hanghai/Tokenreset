Usage cap reached — How to restore access after hitting the limit

'Usage cap reached' typically appears when API calls or advanced features (long context, image generation) hit their consumption limit.

Usage cap reached. Your access will be restored shortly.
API / 高级功能限额提示

Difference from message limits

Message limits cap conversation turns, while usage caps cap resource consumption (token count, compute time, generation count). Usage caps are usually higher but deplete faster.

Automatic recovery time

After hitting a usage cap, access is automatically restored at the end of the current billing cycle. Daily caps recover within 24 hours; monthly caps wait until month-end.

How to request a limit increase

  • Submit a limit increase request in account settings
  • Contact support with your use case and needs
  • Upgrade to a higher subscription tier
  • Join Enterprise for custom quotas

FAQ

Do in-flight requests get lost?

Completed results are preserved. Unfinished requests are interrupted and return an error — no existing data is lost.

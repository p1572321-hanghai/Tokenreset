Usage cap reached — 用量上限已达，如何恢复访问

「Usage cap reached」通常出现在 API 调用或高级功能（如长上下文、图片生成）达到用量上限时。

Usage cap reached. Your access will be restored shortly.
API / 高级功能限额提示

和消息限额的区别

消息限额（message limit）针对对话次数，而 usage cap 针对资源消耗量（如 token 数、计算时长、生成次数）。后者通常额度更大，但消耗也更快。

自动恢复时间

达到 usage cap 后，系统会在当前计费周期结束时自动恢复。按日重置的通常在 24 小时内恢复，按月重置的则需等到月底。

如何申请提升限额

  • 在账户设置中提交限额提升申请
  • 联系客服说明使用场景和需求
  • 升级到更高等级订阅
  • 加入企业版获得定制配额

常见问题

被限后已经发送的请求会丢失吗？

已完成的请求结果会保留，未完成的请求会被中断并返回错误，不会丢失已有数据。

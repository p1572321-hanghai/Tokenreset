怎么看剩余额度？各 AI 助手用量查询方法汇总

不同产品查看剩余额度的方式不同：有的在设置页直接显示，有的需要输入命令，有的只能通过 API 后台查询。

网页版查看方法

  1. 打开产品官网并登录账号
  2. 点击左下角头像或设置图标
  3. 在账户/订阅页面查看「用量」或「Usage」板块
  4. 部分产品在对话框输入 /usage 可直接查看剩余次数

常用 /usage 命令

在对话框输入以下命令可快速查看用量：

  • /usage — 显示当日已用和剩余消息数
  • /limit — 显示当前账户等级的额度上限
  • /status — 显示账户状态和订阅信息

API 用量查询

API 用户可通过以下方式监控用量：

  • 登录 API 控制台，在 Usage 页面查看 token 消耗
  • 调用 /v1/usage 接口获取程序化用量数据
  • 设置用量告警，在达到阈值时接收通知

常见问题

为什么显示的剩余额度和实际可用不一致？

部分产品的额度显示有延迟，实际可用次数以系统实时计算为准。建议以对话框提示为准。

可以查看历史用量记录吗？

API 用户可在控制台查看完整历史用量；网页版通常只显示当日用量，不保留历史记录。
